# Gap index

A gap is a place where the accepted architecture, the code and the runtime
disagree, or a question the evidence cannot settle. It is never resolved by
guessing: decisions go to the owner, evidence goes in the gap.

Each entry gives:

- **Governs:** the decision or `PROBLEM.md` line behind it.
- **Now:** the current state, with evidence.
- **Target:**
- **Closes when:** testable acceptance criteria.
- **Needs:** whose decision or action.
